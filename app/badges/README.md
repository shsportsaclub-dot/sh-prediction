# SH Team Ball Badges

Put an approved badge here as `<slug>.png` (or `.webp`), 512x512 or larger, transparent background, and add the slug to
`manifest.json`. Slug = team name in lower case, spaces as "-", e.g. `uae-bulls.png`, `new-zealand.png`, `new-zealand-women.png`.

Teams without a file get the SH generated ball badge (SVG, drawn in the browser) in the same style: leather ball in the
team colour, gold seam, gold short name. Badges must be original SH artwork, never a copy of a team's official logo.
